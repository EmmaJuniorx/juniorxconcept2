# Juniorx Concept Website

Static, responsive Juniorx Concept website built for GitHub + Netlify.

## Files
- index.html
- style.css
- script.js
- assets/juniorx-concept-logo.png

## Before launch
1. Replace the placeholder WhatsApp number in `index.html`.
2. Replace `hello@juniorxconcept.com` with the official email.
3. Replace the sample portfolio visuals with real project screenshots.
4. Connect the Juniorx AI buttons to the curated assistant when ready.
5. Add real social links.

No backend is required for the current version.
